How this works (no fakes)

  1. Run Pipeline starts a real GitLab pipeline on the real runner: Build → Unit → Integration.
  2. Integration runs tests/integration/ against the real config app/db/pool.py (pool=5, workers=6) and deterministically fails.
  3. The live LLM (badge above) receives the full job trace + the failing source file + commit diff — no canned answers; if the LLM is down the badge says fallback and a curated analysis is used, clearly labeled.
  4. Approve Auto-Fix applies the LLM patch to the real files in a git worktree, pushes a branch and opens a real MR. If the patch can't be applied it attaches it for review and says so — it never fakes success.
  5. The MR's own pipeline verifies the fix; with Autonomous on, the MR is merged via the real GitLab API only after it goes green and the risk gates pass.
  6. All KPIs are measured from this session + live GitLab data. Reset demo zeroes the session counters.
